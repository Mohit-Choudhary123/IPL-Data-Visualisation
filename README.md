
# IPL Data Visualisation 🏏

"An interactive data visualization project analyzing IPL match statistics using Python, Pandas, Matplotlib, Seaborn, and Plotly."

This project explores historical Indian Premier League (IPL) datasets to uncover deep insights, trends, and patterns about teams, players, matches, and venues. It utilizes static plotting for deep analysis and interactive charting for dynamic exploration.

---

## 🚀 Features & Insights Explored
* **Team Performance Analysis:** Win percentages, toss decisions, and home vs. away ground advantages.
* **Batsmen & Bowler Stats:** Top run-scorers, highest strike rates, leading wicket-takers, and economical bowlers.
* **Match Dynamics:** Impact of winning the toss on winning the match, runs distribution across overs, and venue-specific trends.
* **Interactive Dashboards:** Dynamic plots built with Plotly to zoom, hover, and filter data on the fly.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation:** NumPy, Pandas
* **Static Data Visualization:** Matplotlib, Seaborn
* **Interactive Visualizations:** Plotly Express / Graph Objects
* **Environment:** Jupyter Notebook
